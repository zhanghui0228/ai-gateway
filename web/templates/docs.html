概览

AIGateway 对外提供统一的 OpenAI 兼容 API，同时内部完成 Anthropic Claude、Google Gemini、Azure OpenAI 等协议的自动转换。你只需一个 Base URL + 一个 API Key，即可调用全球主流模型。

⬡
统一接口
OpenAI 格式通吃全部模型
⇄
协议转换
Claude / Gemini / Azure 自动适配
⚡
流式输出
SSE 实时推送,逐 token 返回
◈
auto 路由
model=auto 自动选最优渠道

鉴权方式

在请求头中携带 API Key 进行鉴权。Key 由控制台「API Key 管理」签发，可设置额度、模型白名单与过期时间。

// 请求头
Authorization: Bearer <你的 API Key>
提示：Key 格式为 sk-gw-...，在控制台签发后立即复制保存，列表只显示掩码。

请求地址

# 本机默认
BASE_URL = http://127.0.0.1:5100

# Docker 部署(容器内互通)
BASE_URL = http://host.docker.internal:5100

聊天补全

POST/v1/chat/completions
最核心的对话接口，支持流式与非流式。兼容 OpenAI Chat 格式，内部自动转 Claude / Gemini / Azure 协议。

请求示例

curl http://127.0.0.1:5100/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-gw-xxx" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true
  }'

请求参数

字段类型说明
modelstring模型 ID，或填 auto 由网关自动选择
messagesarray对话消息列表，支持 system / user / assistant
streambool是否流式返回，默认 false
temperaturefloat采样温度 0~2，默认 0.7
max_tokensint最大输出 token 数

响应示例(非流式)

{
  "id": "chatcmpl-xxx",
  "model": "gpt-4o",
  "choices": [{
    "message": {"role": "assistant", "content": "你好!有什么可以帮你的?"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 8, "completion_tokens": 12, "total_tokens": 20}
}

文本补全

POST/v1/completions
经典文本补全接口，给定 prompt 返回续写结果。
curl http://127.0.0.1:5100/v1/completions \
  -H "Authorization: Bearer sk-gw-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-chat", "prompt": "从前有座山", "max_tokens": 100}'

嵌入向量

POST/v1/embeddings
文本向量化接口，用于语义搜索、聚类等场景。
curl http://127.0.0.1:5100/v1/embeddings \
  -H "Authorization: Bearer sk-gw-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "text-embedding-3-large", "input": "要向量化的文本"}'

图像生成

POST/v1/images/generations
文生图接口，当前支持 DALL·E 等模型。
curl http://127.0.0.1:5100/v1/images/generations \
  -H "Authorization: Bearer sk-gw-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model": "dall-e-3", "prompt": "一只在月球上奔跑的猫", "n": 1}'

模型列表

GET/v1/models
返回当前 API Key 有权访问的全部模型列表。第一个固定为 auto，表示由网关自动路由。
curl http://127.0.0.1:5100/v1/models \
  -H "Authorization: Bearer sk-gw-xxx"

多协议转换

网关内部自动完成协议转换，你只需用 OpenAI 格式发请求，即可调用 Claude、Gemini、Azure 等模型：

目标模型协议说明
Claude 系列Anthropic ↔ OpenAI自动转 messages / system / streaming 格式
Gemini 系列Gemini ↔ OpenAI自动转 contents / parts / safety 字段
Azure OpenAIAzure ↔ OpenAI自动映射部署名与 api-version
DeepSeek / Kimi / 通义 / 智谱OpenAI 兼容原生兼容，直接转发
提示：渠道配置中可设置「模型映射」，将对外暴露的模型名映射到上游真实模型 ID。

流式响应

设置 stream: true 后，服务端以 SSE (Server-Sent Events) 逐 token 推送结果，最后一条为 data: [DONE]。

data: {"choices": [{"delta": {"content": "你"}}]}

data: {"choices": [{"delta": {"content": "好"}}]}

data: {"choices": [{"delta": {}, "finish_reason": "stop"}]}

data: [DONE]
注意：流式响应需在客户端正确处理 SSE 协议，推荐使用 OpenAI SDK 直接对接。

auto 智能路由

将 model 设为 auto，网关会根据 API Key 白名单、渠道优先级与可用模型自动选择最优渠道。

curl http://127.0.0.1:5100/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-xxx" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "你好"}]}'
提示：可在控制台「系统设置」配置 auto 偏好模型列表，未配置时回退到 Key 白名单 / 全部模型。
