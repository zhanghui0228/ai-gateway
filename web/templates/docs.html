AIGateway 对外接口文档

OPENAI-COMPATIBLE UNIFIED API
所有接口与 OpenAI SDK 完全兼容:将 base_url 指向本网关, api_key 填网关签发的 Key(sk-gw-*)即可访问所有已配置渠道的模型,包括 Claude / Gemini 等原生协议模型(网关自动完成协议转换)。

接口清单

POST/v1/chat/completions核心
对话补全。支持 stream 流式(SSE)、工具调用、多模态图片(base64)。请求体与 OpenAI 一致:model 填网关中配置的模型名,messages / temperature / max_tokens / tools / stream 等参数原样透传。
POST/v1/completions
文本补全(旧版接口)。参数同 OpenAI。
POST/v1/embeddings
文本向量化。Gemini 原生 embedding 模型已自动转换为 OpenAI 格式。
POST/v1/images/generations
图片生成(仅支持提供该能力的 OpenAI 兼容渠道)。
GET/v1/models
当前 Key 可用的模型列表(自动聚合所有启用渠道,并按 Key 白名单过滤)。
GET/docs本页
本接口文档。

快速接入 · Python (openai SDK)

# pip install openai
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:5100/v1",
    api_key="sk-gw-你的网关Key",
)

# 非流式
resp = client.chat.completions.create(
    model="deepseek-chat",          # 任意已配置模型,含 claude / gemini
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

# 流式
stream = client.chat.completions.create(
    model="claude-sonnet-4-5",
    messages=[{"role": "user", "content": "写一首诗"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

curl 调用示例

# 非流式
curl http://127.0.0.1:5100/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-你的Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-2.5-flash",
    "messages": [{"role": "user", "content": "你好"}]
  }'

# 流式(SSE):逐行 data: {...},以 data: [DONE] 结束
curl -N http://127.0.0.1:5100/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-你的Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "讲个笑话"}],
    "stream": true
  }'

JavaScript (fetch) 示例

// 流式读取 SSE
const resp = await fetch("http://127.0.0.1:5100/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk-gw-你的Key",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "qwen-plus",
    messages: [{ role: "user", content: "你好" }],
    stream: true,
  }),
});
const reader = resp.body.getReader();
const decoder = new TextDecoder();
let buf = "";
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });
  const lines = buf.split("\n\n");
  buf = lines.pop();
  for (const line of lines) {
    if (!line.startsWith("data: ")) continue;
    const payload = line.slice(6);
    if (payload === "[DONE]") break;
    const json = JSON.parse(payload);
    const delta = json.choices?.[0]?.delta?.content;
    if (delta) document.body.append(delta);
  }
}

auto 智能选型

model 填 "auto" 时,网关自动选择实际调用的模型,适合"只管问、不挑模型"的场景:
· 优先按管理员在 系统设置 → auto 模型偏好 配置的顺序尝试(如 deepseek-chat, gpt-4o-mini)
· 未配置偏好时:按 Key 白名单 → 全部启用渠道(渠道优先级降序)生成候选
· 某模型无可用渠道(如全部熔断)时自动降级到下一候选,仍受故障转移与熔断保护
· 实际使用的模型在响应的 model 字段中返回 
curl http://127.0.0.1:5100/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-你的Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "你好"}]
  }'

错误码与说明

401 — API Key 缺失 / 无效 / 已过期   |   403 — Key 无权访问该模型(白名单限制)
429 — Key 令牌额度已耗尽   |   404 — 没有可用渠道支持该模型   |   502 — 所有候选渠道尝试失败(明细见控制台用量日志)

· 网关自动完成故障转移:单渠道失败会按优先级/权重自动切换下一渠道,客户端无感知
· 流式响应默认注入 stream_options.include_usage,最后一个 chunk 携带精确 usage 用于计费
· 未配置单价的模型按 0 元计费;额度扣减与费用统计详见管理控制台
